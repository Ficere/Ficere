# Profile maintenance

The profile title is carried by the capsule-render banner: `AI × SynBio` with `Protein design · Scientific systems`. The original star-chart/protein artwork remains the first visual, and the only overlay motion is the approved solid-color typewriter sequence in its empty left field. The standalone typing strip is kept as a source asset but is no longer linked from README.

The embedded hero typewriter uses four solid-color lines: “From atoms to assays”, “Design → validate → learn”, “Protein design → data feedback”, and “BaZi, but schema-validated”. It uses a 10 second clip-reveal loop with a solid cyan cursor, with a static first-line fallback when reduced motion is requested. Desktop and mobile use different coordinates so the text stays inside the dark left region.

The capsule banner has dark and light variants for GitHub theme matching, plus separate mobile dimensions. The visible subtitle is intentionally short to keep the left-aligned title and subtitle inside the safe area. The capsule assets are self-hosted outputs based on capsule-render; the original artwork is not used as a capsule background.

The Day section uses dark and light research-loop SVGs. The loop completes in 13 seconds and its six motion rings respond at 0, 2.1, 4.2, 6.5, 8.7, and 10.8 seconds. The `.motion` class is hidden for `prefers-reduced-motion`.

The Night section links two matching cards: Tianji and the macro-regime-mapping side quest. Both have desktop/mobile and dark/light SVGs. Keep the cards linked to `Ficere/tianji` and `Ficere/macro-regime-mapping`; do not describe either as a biology result.

The galaxy-profile generator is vendored under `generator/`. Its curated `config.yml` contains three focus sectors and public project links only. `assets/generated/tech-stack.svg` and its light variant are the visible focus card; the generated project constellation is retained as an asset but is no longer shown in README. Run `python -m generator.main generate` with `GITHUB_TOKEN` to refresh locally. The scheduled workflow is `.github/workflows/galaxy-profile.yml`.

The 3D contribution observatory is generated by `.github/workflows/profile-3d.yml`. The README now keeps it expanded. Dark mode uses `profile-night-view.svg`; light mode uses `profile-green.svg`. The workflow runs daily or through `workflow_dispatch`, pins the upstream action to an immutable commit, and copies generated SVGs into `assets/profile-3d-contrib/`.

`.github/workflows/snake.yml` remains the independent contribution Snake workflow. It runs every 12 hours, on pushes to `main`, and through `workflow_dispatch`; its light and dark SVGs are published to the `output` branch. The light output uses a pale grid with brass/cyan accents for GitHub light mode; the dark output keeps the midnight palette.

SynAster Hub is described only as a public protein-design skill bundle for AI agents. The README does not claim ownership, authorship, or a specific personal responsibility for the platform.
