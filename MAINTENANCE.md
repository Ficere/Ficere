# Profile maintenance

The profile title is `AI × Synthetic Biology`. The main hero remains the original star-chart/protein artwork in `assets/hero-archive.png` with local animated SVG layers in `assets/hero-archive-animated.svg` and `assets/hero-archive-animated-mobile.svg`. Static PNG variants are selected for reduced motion.

The main hero startup sequence is an 8 second loop: brass ticks wake first, a cyan scan crosses the protein field, molecular nodes respond, and an energy point returns along the orbit. The typing strip uses a 10 second opacity rotation on both sizes. Keep the static PNG and reduced-motion media sources intact.

`assets/capsule-hero-prototype.svg` and `assets/capsule-hero-prototype-mobile.svg` are self-hosted alternatives generated from capsule-render. They are shown in a collapsed README section for comparison; the instrument hero remains the default. The prototype is a generated wave banner and does not use the star-chart image as a background.

The Day section uses the research-loop SVGs. The loop completes in 13 seconds and its six motion rings respond at 0, 2.1, 4.2, 6.5, 8.7, and 10.8 seconds. The `.motion` class is hidden for `prefers-reduced-motion`.

The Night section links to the tianji cards. The fixed card text is “BaZi, but schema-validated.” and “A reproducible reading for an irreproducible universe.” Keep it linked to `Ficere/tianji` and avoid describing it as a biology result.

The galaxy-profile generator is vendored under `generator/`. Its curated `config.yml` contains three focus sectors and public project links only. `assets/generated/tech-stack.svg` is the visible focus card; the generator also maintains the galaxy header, stats card, and project constellation. Run `python -m generator.main generate` with `GITHUB_TOKEN` to refresh locally. The scheduled workflow is `.github/workflows/galaxy-profile.yml`.

The 3D contribution observatory is generated by `.github/workflows/profile-3d.yml`. The workflow runs daily or through `workflow_dispatch`, pins the upstream action to an immutable commit, and copies generated SVGs into `assets/profile-3d-contrib/`. The checked-in `profile-night-view.svg` remains a safe visual fallback until the first successful run or during a temporary service failure.

`.github/workflows/snake.yml` remains the independent contribution Snake workflow. It runs every 12 hours, on pushes to `main`, and through `workflow_dispatch`; its light and dark SVGs are published to the `output` branch. Do not add a second static contribution heatmap.

SynAster Hub is described only as a public protein-design skill bundle for AI agents. The README does not claim ownership, authorship, or a specific personal responsibility for the platform.
